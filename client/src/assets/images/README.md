# Imágenes importadas en la app

El QR (`genfeb_qr.png`) se importa aquí para que **Vite** genere la URL correcta en desarrollo y en build.

```ts
import qrGenfebUrl from "@/assets/images/genfeb_qr.png";
```

Si cambias el archivo, reemplaza `genfeb_qr.png` en esta carpeta.

Puedes mantener una copia en `client/public/assets/images/` solo como respaldo, pero la fuente usada en la UI es esta.
