# Imágenes importadas en la app

El QR (`applia_qr.png`) se importa aquí para que **Vite** genere la URL correcta en desarrollo y en build.

```ts
import qrAppliaUrl from "@/assets/images/applia_qr.png";
```

Si cambias el archivo, reemplaza `applia_qr.png` en esta carpeta.

Puedes mantener una copia en `client/public/assets/images/` solo como respaldo, pero la fuente usada en la UI es esta.
